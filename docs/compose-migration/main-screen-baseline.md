# Main画面 Compose移行前ベースライン

## 目的

Main画面をJetpack Composeへ移行する際に、現行XML実装の表示と操作を比較できるようにする。
この文書と `baseline` ディレクトリの画像は、移行後の受け入れ基準として使用する。

## 撮影条件

- 撮影日: 2026-08-10
- APK: `net.mm2d.timer.debug` 0.12.7
- 端末: Android Emulator `Medium_Phone_API_37`
- Android API: 37
- 画面: 2400 x 1080 px、横向き
- 設定: 初期設定（黒背景、白前景、LED 7セグメント、時間表示なし、ミリ秒表示あり）
- システムバー: 全画面設定により非表示

## 共通表示

- 背景は設定された背景色で画面全体を塗る。
- 数字表示は、操作ボタンの上側にある領域内で縦横比を維持し、可能な限り大きく中央配置する。
- 左端に第1操作ボタン、中央に第2操作ボタン、右端に設定ボタンを配置する。
- 操作ボタンは80 x 40 dp、左右端のマージンは16 dp、下端のマージンは8 dpである。
- 前景と背景の明度に応じて、操作ボタンの背景、枠線、アイコン色を切り替える。
- 操作後および画面開始時、ボタンの不透明度を一度100%にしてから、設定値まで1500 msで変化させる。
- 設定ボタンを押すと `SettingsActivity` を開く。
- 全画面、画面方向、前景色、背景色、フォント、ミリ秒表示などはDataStoreの設定変更に追従する。

## モード別挙動

### 時計

- 第1、第2操作ボタンは `INVISIBLE` になり、設定ボタンだけを表示する。
- 24時間表示では時・分・秒を表示し、12時間表示ではAM/PMも表示する。
- 秒の切り替わりに合わせて約1秒間隔で更新する。
- 時計モード中は画面を常時点灯する。
- 数字領域のタップでは状態を変更しない。

### ストップウォッチ

- 停止中の第1操作ボタンは開始、第2操作ボタンはリセットを表す。
- 第1操作ボタンまたは数字領域のタップで開始／停止を切り替える。
- 開始すると第1操作ボタンを一時停止アイコンへ変更し、画面を常時点灯する。
- 第2操作ボタンは、実行中なら停止したあと経過時間を0へ戻す。
- 時間表示なしでは最大 `99:59.99`、時間表示ありでは最大 `9:59:59.99` とする。
- 最大値に達した場合は自動停止する。
- 実行中にActivityが停止すると開始時刻とマイルストーンを保存し、復帰時に経過時間を反映して再開する。

### タイマー

- 停止中の第1操作ボタンは開始、第2操作ボタンは時刻設定を表す。
- 残り時間が0より大きい場合、第1操作ボタンまたは数字領域のタップで開始／停止を切り替える。
- 残り時間が0の場合、第1操作ボタンまたは数字領域のタップで時刻設定ダイアログを開く。
- 第2操作ボタンは、実行中なら停止したあと時刻設定ダイアログを開く。
- 開始すると第1操作ボタンを一時停止アイコンへ変更し、画面を常時点灯する。
- 残り時間が0に達すると停止し、停止音を再生する。
- 設定されたタイマー初期値が変更された場合、実行を停止して新しい値を表示する。
- 実行中にActivityが停止すると開始時刻とマイルストーンを保存し、復帰時に残り時間を反映して再開する。

### 時刻設定ダイアログ

- 時間表示なしでは分を0〜99、秒を0〜59の範囲で設定する。
- 時間表示ありでは時を0〜9、分と秒を0〜59の範囲で設定する。
- `+5分`、`+30秒`、`+5秒`、`-5分`、`-30秒`、`-5秒`、`リセット`を提供する。
- 加減算結果は許容範囲内へ丸める。
- `OK` で値を保存し、`キャンセル` では変更しない。

## 外部Intent契約

`MainActivity` は `singleTask` であり、初回起動時と `onNewIntent()` で外部指示を処理する。

| Extra           | 値                               | 挙動                                 |
|-----------------|---------------------------------|------------------------------------|
| `EXTRA_MODE`    | `CLOCK` / `STOPWATCH` / `TIMER` | 対象モードへ切り替える                        |
| `EXTRA_COMMAND` | `START`                         | タイマーまたはストップウォッチを未実行時に開始する          |
| `EXTRA_COMMAND` | `STOP`                          | 実行中の場合に停止する                        |
| `EXTRA_COMMAND` | `SET`                           | `EXTRA_TIME` の値を設定し、実行中なら停止する      |
| `EXTRA_COMMAND` | `SET_AND_START`                 | `EXTRA_TIME` の値を設定して開始する           |
| `EXTRA_TIME`    | ミリ秒を表す `Long`                   | `SET` / `SET_AND_START` の時刻として使用する |

- `EXTRA_MODE` がない、または不明な値の場合はIntentを処理しない。
- コマンド名が不明、型が異なる、必要な `EXTRA_TIME` がない場合は状態を変更しない。
- 対象モードがまだアクティブでない場合は、モードがアクティブかつActivityが再開状態になってからコマンドを処理する。

## Compose移行後の受け入れ基準

- 上記6状態のレイアウト、桁比率、ボタン配置、色が基準画像と一致する。
- 共通表示、モード別挙動、外部Intent契約を維持する。
- バックグラウンド復帰後も実時間を反映した値を表示する。
- 時計は秒境界、タイマーとストップウォッチは表示精度に合う周期で更新される。
- 非表示のボタンがレイアウト上の配置を崩さない。
- 既存設定と保存済み実行状態との互換性を維持する。
